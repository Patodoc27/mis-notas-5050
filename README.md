# Mis notas · 5° TM · Colegio 5050

App instalable (PWA — Android / iPhone) para que los estudiantes de 5° año
turno mañana consulten sus notas del 3er trimestre.

- Ingreso tolerante por apellido y nombre (tildes, mayúsculas, orden).
- Lee en vivo la planilla de Google Sheets (gviz).
- Muestra actividades con nota, pendientes y la nota del trimestre.
- Botones al Pasapalabra IA y al Cuestionario Virtual.

**Docente:** la planilla debe estar compartida como "Cualquier persona con
el enlace → Lector". El ID está en `SHEET_ID` dentro de `index.html`.
